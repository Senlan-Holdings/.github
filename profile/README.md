## 我们关注

- **企业工具与系统**：围绕实际工作建设稳定、清晰、可维护的工具与系统。
- **智能工作流与自动化**：让 AI 与自动化进入真实流程，并保留必要的人工判断和安全边界。
- **数字产品与技术验证**：从需求澄清、原型验证到工程交付，以可验证结果推动持续改进。

## 协作方式

项目默认采用私有协作，仅向获授权成员开放相应内容。公开主页只介绍智能中心的方向，不承载内部资料、成员信息或项目入口。
